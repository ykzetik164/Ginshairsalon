# GINS Next.js Site

這是 GINS 官網的 Next.js 雛形。內容先用佔位資料建立，後續可替換成正式照片、價目、設計師與預約連結。

## 常用檔案

- `src/data/site.ts`：店名、地址、服務、價目、設計師、作品集資料
- `public/images/`：網站圖片
- `src/app/page.tsx`：首頁組裝
- `src/app/globals.css`：整體視覺樣式

## 預覽

安裝 Node.js 後，在這個資料夾執行：

```bash
npm install
npm run dev
```

然後打開 `http://localhost:3000`。
